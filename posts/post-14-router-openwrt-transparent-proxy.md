## 序言：什么是全屋“透明代理（Transparent Proxy）”？

对于拥有智能电视、Apple TV、游戏主机（PS5 / Xbox Series X / Switch）以及大量 Smart Home 设备的发烧友家庭来说，“全屋透明代理”是网络体验的终极形态。

**透明代理** 的优势在于：
- **设备零配置**：手机、电视、游戏机连接家里 Wi-Fi 就能无感访问外网，无需安装任何客户端；
- **全屋智能分流**：国内流量走本地宽带直连、海外流量自动切专线；
- **解决电视/游戏机局限**：彻底解决 PS5 联机卡顿、Apple TV 无法安装常规客户端的痛点。

本篇文章中，鹅将为你硬核拆解 **iKuai (主路由) + OpenWrt (旁路由)** 的黄金双软路由架构，并重点破解 **DNS 防污染与网关环路** 绝症！

## 一、 黄金架构拆解：iKuai 主路由 + OpenWrt 旁路由

在软路由拓扑设计中，“单旁路由”模式容易因为旁路由宕机导致全屋断网。因此，极客圈最推崇的架构是 **iKuai 主路由（负责拨号/DHCP/流控） + OpenWrt 旁路由（负责透明代理与科学上网）**。

```
                          ┌────────────────────────────────┐
                          │         光猫 (Modem)           │
                          └───────────────┬────────────────┘
                                          │ 宽带拨号 (PPPoE)
                                          ▼
                          ┌────────────────────────────────┐
                          │   iKuai 主路由 (192.168.1.1)    │
                          │ (负责多拨、DHCP分配、流控分流) │
                          └───────┬────────────────┬───────┘
                                  │                │
            普通设备网关 192.168.1.1  │                │ 开启代理设备网关 192.168.1.2
                                  ▼                ▼
                     ┌──────────────────┐    ┌───────────────────────────┐
                     │ 智能电视 / 打印机│    │ OpenWrt 旁路由(192.168.1.2)│
                     │ (直连国内宽带)   │    │ (运行 OpenClash / PassWall│
                     └──────────────────┘    └─────────────┬─────────────┘
                                                           │ 海外流量切专线
                                                           ▼
                                                     Apple TV / PS5
```

### 1. 为什么选择 iKuai 作主路由？
iKuai 在多拨叠加、DPI 流量识别与硬件流控上极其稳定，常年运行绝不掉线。

### 2. 为什么选择 OpenWrt 作旁路由？
OpenWrt 拥有丰富的插件生态（OpenClash、PassWall、SSR-Plus），能完美承载 Clash Meta 内核的复杂分流算法。

## 二、 关键网络参数配置步骤（防止网关环路与死锁）

### 步骤 1：OpenWrt 旁路由网络接口设置
- **IPv4 地址**: 设为固定 IP `192.168.1.2`
- **IPv4 网关**: 指向 iKuai 主路由 `192.168.1.1`
- **IPv4 DNS 服务器**: 设为 `192.168.1.1` 或 `114.114.114.114`
- **DHCP 服务**: **必须关闭** OpenWrt 的 DHCP 服务（防止与 iKuai 冲突抢夺 IP）。

### 步骤 2：iKuai 主路由 DHCP 高级设置
在 iKuai 系统的 `网络设置 ➔ DHCP 服务端` 中：
- 如果想让**全屋所有设备自动科学上网**：将 DHCP 的“网关”直接填为 `192.168.1.2`（旁路由 IP）；
- 如果想让**指定设备（如仅 Apple TV/PS5）科学上网**：DHCP 网关依然保持 `192.168.1.1`，仅在 Apple TV 或 PS5 的网络设置中，手动将网关改为 `192.168.1.2`。

## 三、 绝症破解：DNS 防污染与回国流量优化 (MosDNS / OpenClash)

透明代理最常遇到的坑就是 **DNS 污染**：国内域名被污染成海外 IP，走代理变慢；或者海外域名在本地解析成错误 IP，导致无法访问。

```text
┌───────────────────────────────────────────────────────────┐
│                    MosDNS 智能防污染逻辑                   │
└───────────────────────────────────────────────────────────┘
 用户 DNS 请求 ──> MosDNS 智能分流引擎 
                    ├── 国内域名 (如 aliyun.com)  ──> 走 DNSPod/阿里 DNS (直连)
                    └── 海外域名 (如 google.com)  ──> 走 8.8.8.8 (通过代理加密解析)
```

### 解决方案：OpenClash 开启 Fake-IP 模式
在 OpenClash 插件设置中：
1. DNS 模式选择 **`Fake-IP` (伪装 IP 模式)**；
2. 开启 **本地 DNS 劫持** 功能；
3. 禁用 IPv6 解析（如果不需要 IPv6），有效防止 IPv6 导致的流量绕过代理泄露。
