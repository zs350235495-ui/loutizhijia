## 💡 03. 梯子之家·防踩坑四大铁律

在挑选与使用代理服务时，请务必牢记以下避坑要点：

- **⚠️ 绝不盲目年付“超低价大包裹”**：凡是几十元包年宣称几千 G 流量的个人小作坊，跑路概率超过 80%，建议按月或按季续费。

- **⚠️ 区分规则模式与全局模式**：日常使用请务必保持“规则分流模式”，避免微信、淘宝等国内应用走代理被限制登录或扣减套餐流量。
