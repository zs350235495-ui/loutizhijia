一、 软件下载与安装避坑（Windows & macOS）

1. 官方开源获取渠道

千万不要在百度或谷歌搜索结果的第一页随意点击“第三方破解网站”或广告下载！许多包含了恶意木马程序。
  • 官方 GitHub 开源仓库: GitHub 搜索 clash-verge-rev/clash-verge-rev
  • 版本选择:
  • Windows: 下载 Clash.Verge_x.x.x_x64-setup.exe (或 Portable 便携版)；
  • Mac (Intel 芯片): 下载 Clash.Verge_x.x.x_x64.dmg；
  • Mac (Apple Silicon M1/M2/M3/M4): 下载 Clash.Verge_x.x.x_aarch64.dmg。

2. macOS 首次打开提示“无法验证开发者”解决办法

在 Mac 上打开提示软件已损坏或无法打开时，无需慌张：
  1. 打开终端（Terminal）；
  2. 输入命令：sudo xattr -r -d com.apple.quarantine /Applications/Clash\ Verge.app 并回车输入密码即可解除隔离。

二、 3 步核心配置实操：从订阅导入到系统代理


[步骤 1: 复制订阅] ──> [步骤 2: 粘贴至 Profiles 导入] ──> [步骤 3: 开启 System Proxy 开启滑行]

步骤 1：复制机场机长暗号/订阅链接

前往你的机场后台（如【航班推荐榜】中推荐的环球梯、大佬云等），找到 “Clash 订阅 / 一键导入” 按钮，复制 URL 链接。

步骤 2：导入订阅配置文件 (Profiles)

  1. 打开 Clash Verge Rev 客户端；
  2. 点击左侧边栏的 订阅 (Profiles) 菜单；
  3. 在上方输入框粘贴刚才复制的订阅 URL 链接；
  4. 点击右侧的 导入 (Import) 按钮；
  5. 导入成功后，鼠标单击选中该订阅卡片，使其变为高亮激活状态。

步骤 3：开启系统代理 (System Proxy) 或 TUN 模式

  • 常规上网（网页/看视频）: 点击左侧边栏的 设置 (Settings)，开启 系统代理 (System Proxy) 开关，右下角状态栏变成彩色图标即可；
  • 硬核应用（游戏/终端/Uplay/Epic/Steam）: 在设置中找到 TUN 模式 (TUN Mode)，点击安装服务模式（Service Mode）并开启。TUN 模式能够接管整台电脑的所有 UDP/TCP 流量，无需手动配置软件代理地址。

三、 高级技巧：规则分流与策略组切换

在左侧边栏点击 代理 (Proxies)，你将看到清晰的策略组面板：

text
┌───────────────────────────────────────────────────────────┐
│                    Clash Verge 策略组面板                  │
└───────────────────────────────────────────────────────────┘
 🚀 节点选择 (Node Select)  ──>  [ 🇭🇰 香港 IPLC 专线 01  ▼ ]
 🎬 节点流媒体 (Media)       ──>  [ 🇸🇬 新加坡 原生 01      ▼ ]
 🤖 AI 助手 (OpenAI)       ──>  [ 🇺🇸 美国 住宅 IP 01    ▼ ]
 🎯 直连流量 (DIRECT)        ──>  [ 局域网/国内网站       ]

策略组模式详解：

  • 规则模式 (Rule)（推荐）：根据内置规则，访问国内网站（百度、淘宝、哔哩哔哩）自动走 DIRECT 直连，速度极快；访问海外网站自动走节点，省流量且不卡顿。
  • 全局模式 (Global)：强制整台电脑的所有流量全部走选定的海外节点，通常用于测试或特定访问。
  • 直连模式 (Direct)：关闭所有代理，恢复普通网络访问。

四、 常见报错与急救速查

故障现象根源排查解决方案
订阅导入失败 (HTTP 403/500)机场订阅链接被本地 DNS 污染，或需要挂代理更新先开启原有代理，或使用机场提供的“订阅转换”功能生成新链接
开启代理后网页打不开原有系统代理残留，或端口冲突在设置中点击“重置系统代理”，或重启 Clash Verge
Uplay/Epic 客户端登录超时软件不走 HTTP 代理开启 TUN 模式 并重启游戏客户端
