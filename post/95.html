一、 版权检测大揭秘：自制剧 vs 非自制剧的“降级陷阱”

这是 90% 的新手都会落入的认知误区：


【流媒体检测与降级机制】:
用户访问 Netflix ──> 检测出口 IP 属性
                      ├── 判定为机房广播 IP (IDC) ──> 降级模式 (仅允许观看 Netflix 自制剧)
                      └── 判定为原生/家宽 IP (ISP) ──> 完整解锁 (解锁本土特有非自制剧)

1. 什么是 Netflix “自制剧 (Originals)” 与 “非自制剧”？

  • 自制剧（Self-produced）：如《鱿鱼游戏》、《怪奇物语》、《黑暗荣耀》。Netflix 拥有全球独家版权，因此对 IP 审查相对宽松。即使是普通的机房 IP 节点，也能正常播放；
  • 非自制剧（Licensed Content）：如《绝命毒师》、《老友记》、各类日本最新同步动漫。这些剧集存在严格的地域版权限制（例如某部动漫仅限日本 IP 观看，某部电影仅限美国 IP 观看）。
当你的节点 IP 被 Netflix 识别为数据中心广播 IP 时，系统不会直接阻断你登录，而是悄悄隐藏所有非自制剧。你在搜索框里搜索对应剧集时会发现“页面一片空白”，这就是典型的被降级现象。

二、 DNS 解锁与落地住宅重定向技术

为了解决节点原生 IP 昂贵的问题，优质机场通常采用 DNS 分流重定向（DNS Unlock / SNI Proxy） 技术：


用户流量 ──> 机场专线入口 ──> 机场中转机房 
                                 │ (智能识别流媒体请求)
                                 ▼
                     [DNS 分流重定向服务器] 
                                 │ (将流媒体 SNI 流量代理至原生 IP)
                                 ▼
                     [海外原生/家宽落地机] ──> Netflix / Disney+ 官网

通过这种架构，机场可以将普通节点的流量在流媒体访问时动态重定向到具备原生 IP 的落地机上，既保证了全员 4K 不卡顿的高带宽，又完美绕过了流媒体平台的版权黑名单。

三、 实操教程：如何在 Clash / Shadowrocket 中配置“流媒体策略组”

为了避免看视频时占用办公节点的流量，或者防止看奈飞时突然掉线，建议在客户端中配置独立的流媒体策略组。

Clash 智能流媒体分流 YAML 配置

yaml
proxy-groups:
  - name: 🎬 Netflix 奈飞专属
    type: select
    proxies:
      - 🇸🇬 新加坡-流媒体原生IP-01
      - 🇭🇰 香港-IPLC专线-01
      - 🇯🇵 日本-原生ISP-01

  - name: 🏰 Disney+ 迪士尼
    type: select
    proxies:
      - 🇸🇬 新加坡-流媒体原生IP-01
      - 🇺🇸 美国-原生住宅IP-01

rules:
  # Netflix 规则
  - DOMAIN-SUFFIX,netflix.com,🎬 Netflix 奈飞专属
  - DOMAIN-SUFFIX,netflix.net,🎬 Netflix 奈飞专属
  - DOMAIN-SUFFIX,nflximg.net,🎬 Netflix 奈飞专属
  - DOMAIN-SUFFIX,nflxvideo.net,🎬 Netflix 奈飞专属

  # Disney+ 规则
  - DOMAIN-SUFFIX,disneyplus.com,🏰 Disney+ 迪士尼
  - DOMAIN-SUFFIX,disney-portal.my.onetrust.uc.onedrust.com,🏰 Disney+ 迪士尼
