一、 故障 1：节点全红显示“超时 (Timeout)”或 ping 不通

🚨 症状表现

客户端里的所有节点批量显示红色 Timeout，无法打开任何海外网页，但国内百度、微信正常。 


【节点全红超时排查决策树】:

节点全红 ──> 检查 1: 系统时间是否精准到秒？
               ├── 否 ➔ 手动同步系统时间 ➔ [解决！]
               └── 是 ➔ 检查 2: 机场订阅域名是否更换？
                        ├── 是 ➔ 开启备用节点更新订阅 ➔ [解决！]
                        └── 否 ➔ 检查 3: 系统代理端口是否冲突 ➔ [解决！]

🛠️ 3 步排查与急救方法：

  1. 第一步：检查系统时间是否精准（最常见！）
所有的现代加密协议（VLESS、VMess、Hysteria 2）都对时间同步有极度苛刻的要求。只要你的电脑或手机系统时间误差超过 90 秒，握手解密就会直接失败！
  • Windows: 设置 ➔ 时间和语言 ➔ 立即同步时间；
  • Mac: 系统设置 ➔ 通用 ➔ 日期与时间 ➔ 关闭后重新开启自动设置；
  • Android/iOS: 在设置中开启“自动从网络获取时间”。
2. 第二步：检查系统代理端口占用 检查是否有其他软件（如迅雷、百度网盘、Fiddler、其他代理工具）占用了 Clash 的默认端口 7890。在 Clash 设置中尝试修改混合端口为 7899 或 10808。
  1. 第三步：测试 DNS 是否被污染
在终端（cmd / Terminal）输入 nslookup google.com。如果返回的 IP 是 127.0.0.1 或国内保留 IP，说明你的 DNS 被污染了。在客户端中开启 TUN 模式 或更改 DNS 为 1.1.1.1。

二、 故障 2：订阅链接更新失败 (HTTP 403 / 500 / Fetch Error)

🚨 症状表现

在 Clash 或 Shadowrocket 中点击“更新订阅”时，弹窗报错 Fetch Error、403 Forbidden 或 SSL Handshake Failed。

🛠️ 3 步排查与急救方法：

  1. 使用现有节点“挂代理更新”：机场的订阅服务器域名可能遭到了 GFW 临时拦截。先开启旧有的可用节点，然后再点击更新订阅；
  2. 复制新的订阅地址：登录机场官网后台，检查机场主是否由于域名受击而更换了全新的订阅链接；
  3. 利用订阅转换服务 (Subconverter)：如果机场原生链接在本地被阻断，可以将订阅链接粘贴至可信的第三方订阅转换平台生成新配置。

三、 故障 3：能发微信QQ，但所有浏览器网页都打不开

🚨 症状表现

电脑连接网络后，微信、QQ 聊天完全正常，但 Chrome、Edge 浏览器无论输入什么网址都提示 ERR_PROXY_CONNECTION_FAILED（无法连接到代理服务器）。

🛠️ 3 步排查与急救方法：

  1. 清除系统代理残留（Windows）：当 Clash 非正常关机（如直接拔掉电源或蓝屏）时，Windows 的系统代理开关会被残留留在开启状态。
  • 解决方案：按 Win + i 打开设置 ➔ 网络和 Internet ➔ 代理 ➔ 关闭 “使用代理服务器” 开关。
2. 重置 Winsock 网络目录：以管理员身份打开 cmd 终端，输入 netsh winsock reset 并回车，随后重启电脑即可恢复正常。

四、 故障 4：ChatGPT 提示 Error 1020 / Access Denied

🚨 症状表现

节点连接正常，YouTube 4K 秒开，但打开 chatgpt.com 或 claude.ai 提示 Access Denied 或 Cloudflare 无限验证码。

🛠️ 3 步排查与急救方法：

  1. 切换为原生/住宅 IP 策略组：该节点 IP 已经被 OpenAI 的风控数据库拦截，切换至具备原生 IP 属性的节点；
  2. 清理浏览器 Cookie 与 LocalStorage：Cloudflare 会在你的浏览器存储风控标记。按下 Ctrl + Shift + Delete 清理过去 7 天的 Cookie，或打开无痕模式（Incognito Window） 重新登录；
  3. 使用 Clash 域名分流绑定：参考《ChatGPT 防封指南》，在配置文件中添加 DOMAIN-SUFFIX,chatgpt.com,策略组 强制固定出口。

五、 故障 5：Netflix 只能看自制剧，搜不到特定剧集

🚨 症状表现

搜索《绝命毒师》、《老友记》或最新日本动漫搜不到，只能看《怪奇物语》等 Netflix 自制剧。

🛠️ 3 步排查与急救方法：

  1. 识别 IP 降级：你的节点 IP 属于数据中心机房 IP (IDC)，被 Netflix 降级处理；
  2. 切换至专门的流媒体解锁节点：挑选节点名称中带有 解锁 / Netflix / NF / 原生 标识的线路；
  3. 检查 DNS 重定向：在客户端设置中关闭本地 DNS 覆写，确保走机场的 DNS 智能分流。
